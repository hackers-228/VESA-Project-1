# Student Savings Tracker

## Project Title

**Student Savings Tracker**

## Project Overview

The Student Savings Tracker is a simple console-based Python application that helps students keep track of the money they save every week. Instead of adding their savings manually, the program automatically updates the total savings, shows how much more is needed to reach a goal, and celebrates when the goal is achieved.

This project was developed to practice Python programming fundamentals by solving a real-life problem in a simple and user-friendly way.

## Understanding of the Problem

Students often receive different amounts of pocket money each week. Keeping track of these savings manually can be confusing and may lead to calculation mistakes. This application provides an easy way to record weekly savings, monitor progress, and know exactly when the savings goal has been reached.

## Features Implemented

* Accepts weekly savings from the user.
* Maintains a running total of savings.
* Displays the remaining amount required to reach the goal.
* Allows the user to set a custom savings goal.
* Validates input to prevent negative savings.
* Displays motivational messages as the student gets closer to the goal.
* Tracks the number of weeks taken to achieve the goal.
* Stores and displays a history of weekly savings.
* Shows any extra money saved after reaching the goal.

## How to Run the Program

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal or command prompt.
4. Navigate to the project folder.
5. Run the following command:

```bash
python savings_tracker.py
```

6. Follow the on-screen instructions to enter your weekly savings.
